# 交办背景与计算口径

合规委员会正在复核九有信息披露处罚事项的内部初稿，拟据此修改委员会材料并安排补充核查。请以所附证监会行政处罚决定书〔2026〕9号网页存档及正文定位版为依据，核查内部稿S01至S12的表述。内部初稿未经法律复核，其中的断言须逐项对照决定；最终材料应清楚记录决定认定、个人申辩、监管回应和仍需底层材料核查的事项。

事项涉及2020至2023年年度报告，适用中国内地证券行政监管。资料版本为2026年10月11日取得的决定存档。此次委托范围为决定文本核查、金额勾稽和后续证据计划；法定量罚、刑事或民事责任需另行委托。

为统一金额反推口径，本次核查约定：决定所列金额分子视为固定；公布百分数由真实百分数按小数点后两位四舍五入（正数half-up）得到。若公布百分数为p，则真实百分数范围为[p−0.005,p+0.005)。该约定用于敏感性区间测算，监管实际计算精度尚待确认。结果可显示至分，另保留未舍入计算以便复核。

尚未取得年度报告原件、底层合同、资金流水、群聊、询问笔录、送达及宣布记录。请按具体争点列出所需材料及用途。缴罚与救济期限、禁入期间应先记录决定所述起算事件，取得对应凭证后再计算实际日期。

正文定位版P编号对应原HTML的detail-news元素下直接p元素位置，空段保留序号；它与HTML属于同一来源。可引用P编号或原HTML章节、段首文字。本次委托使用已交资料，外部检索由委员会另行安排。

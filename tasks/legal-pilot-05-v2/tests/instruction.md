# 芦可替尼盐专利无效决定：代理团队复核

文件在 `/workspace/input-data/`：决定原件 `L044-decision-580173.pdf`、按物理页导出的 `L044-page-text.txt`、同事的工作底稿 `briefing.md` 和两份台账的字段约定 `csv-schema.json`。本轮资料只有公开决定和工作底稿；决定提到的专利全文、实验记录、论文、声明及其译文尚未取得。请据已提供材料完成复核，把需要进一步查证的事项列入补件计划。外部检索由后续负责补件的同事另行安排，本轮使用现有文件。

请完成以下工作：

1. 建立证据台账，逐项覆盖请求证据1–16、反证1、反证2-1至2-18及反证3。记录提出方、名称、决定转述角色、公开或出版日期及其精度、首次提交、补交/更正/放弃、真实性与译文确认范围、主张用途、合议组评价、现有技术与引证文件状态，以及底层文件缺口。决定记载了这36件的首次提交日期，请按记录填写。公开或出版日期未记载时留空并标明精度；未单独转述的主张、程序情况或评价，可留空或说明未记载、未单独评价。具体字段的填值约定见schema。
2. 比较优先权、引证文件资格和现有技术资格的判断链，说明决定处理旧法、细则及2006/2023审查指南的方式。围绕在先/在后文本、实验数据和效果描述，分别呈现请求人、专利权人、合议组的立场及你的复核意见。
3. 分别复核以证据2和证据7为起点的创造性路径：前提、区别特征、技术问题和组合启示。结合原件p17–18结构图描述区别1–3及盐形式，分析证据13、16和成盐资料各自能够承担的作用。评估JAK1/2/3、Ki等级、IC50及测定条件能支持多大范围的结论。
4. 对公开充分和说明书支持，分别复核盐的结构确认、ATP条件与活性、疾病用途三组争议，区分专利法第26条第3款和第4款。按盐、方法、组合物、用途梳理权利要求，单独关注60/61的文本关系。无需逐项重做61条权利要求的完整无效审查。
5. 逐条审改工作底稿D01–D08，给出更正或附条件保留的意见。提出有优先级的补件计划，每项写明索取对象、缺口、对应争点、核验办法和缺件时结论的收缩范围。复核可以提出不同于合议组的有条件论证，但需要回应决定记载的理由和现有证据。

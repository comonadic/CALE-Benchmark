# 万国数据中心 REIT 分配测算

你是基金投后财务分析师。财务负责人准备讨论 8,500 万元的分配方案，需要一份能反复调整收入和预留参数的测算底稿。请以 2026 年 3 月 31 日已公布的 2025 年年报为基础，核对历史可供分配金额，评估基准和压力情景下的分配区间，并测算新增预留的承受能力。

材料位于 `/workspace/input-data/`。`F025-2025-annual-report.pdf` 为披露依据，`F025-2025-parsed.txt` 供检索，取数和引用以 PDF 为准。`scenario.json` 是本次财务讨论采用的测算参数及政策前提。请将披露事实和测算假设分开呈现，引用同时注明 PDF 物理页、印刷页和章节。

财务团队需按稳定业务名称继续调整、检索和复核底稿。请按 `model-data-dictionary.md`（同内容结构化字典为 `model-data-dictionary.json`）建立原生工作簿级命名区域，作为模型交接索引。每个必需名称指向对应业务量的一个真实单元格；敏感性每个组合的 D 和上限余量各有名称。可选项目、单位换算倍率、符号和有效范围见字典。名称可指向任意工作表、任意单元格；页面标签措辞、标签与数值的方向和距离、矩阵或长表布局均可自行设计。无需采用示例坐标。缺少必需名称或引用无效视为未满足交接要求的无效交付。

请完成以下工作：

1. 从合并净利润复算基金 EBITDA、扣除未来支出预留前的金额及可供分配金额，列示全部调整项并与披露控制数勾稽。核对报告期间、合同生效日、份额、实际分配和分配政策。
2. 区分基金合并可供分配金额、基金本期收入、项目公司收入、基金经营现金净流量和项目现金净流量。复算项目现金流入减流出，列示基金与项目现金净流量的差额，说明各口径的用途及差额披露的完整程度。
3. 建立可编辑的基准、压力和自定义参数，使用一个情景选择器驱动同一套活动模型。按照参数文件的增量关系测算情景金额 D、正向可分配额、90% 下限、100% 上限、每份金额、拟分配额对上下限的余量及分配状态。保留负 D 的风险信息，明确无正向分配空间的情形。拟分配额为 0 应正常计算；缺少活动参数或拟分配额时，应显示输入不足，避免将空值当作 0。参数范围见参数文件。
4. 对收入下降 0%、5%、10%、15%、20% 和新增预留 0、500、1,000 万元建立二维敏感性分析，逐组合计算 D 和拟分配额对 100% 上限的余量，使用真实公式并核对与活动模型对应点的一致性。测算各收入情景下保持拟分配额不超过上限的新增预留总预算，以及扣除当前新增预留后的剩余空间。目标已不可达时列明缺口；同时检查 90% 下限。
5. 在短说明中提出基准和压力情景下的建议，交代原预留用途、过渡期损益和本期费用的处理，以及 2025 年实际未分配适用的政策条件。明确本测算与完整年度盈利预测、银行可付现金及分配审批之间的关系。

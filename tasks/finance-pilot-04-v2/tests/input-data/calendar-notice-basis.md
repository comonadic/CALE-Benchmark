# 排程的公告依据与运营安排

公告：[上海期货交易所关于2026年休市安排的公告](https://www.shfe.cn/publicnotice/notice/202512/t20251217_829805.html)，发布日期2025-12-17，〔2025〕157号。以下为公告内容的摘要及排程口径，原F047/F042规则文件另行保留。

公告列明2026年元旦、春节、清明节、劳动节、端午节、中秋节和国庆节的休市区间；国庆节为10月1日至7日，10月8日起开市；10月10日属于周末休市。公告没有列出11月或12月的节假日休市区间。

`planning_calendar.csv`根据上述年度安排和周末形成本次基准交易日表。11月、12月按通常周一至周五交易/办理交割业务推算；暂不计后续临时休市、交易所另行调整或特殊顺延。未来如收到临时公告，由运营更新基准并重新计算期限。工作日列用于本次交割业务排程。

`desk_operations_open`及`operations_note`只描述交易台日常后台值守安排。11月24日常规后台暂停，需安排代理办理与回执确认；这一内部安排不改变交易所交易日、规则到期日或申请截止。提交请求的有效性仍按交易所时限审核，实际办理须落实值守安排。

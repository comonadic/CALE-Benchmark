# AG2612交割前头寸与资金准备

请作为交易风控分析员，为风控负责人编制AG2612交割准备底稿，支持交易台安排减仓、期权行权和资金补足。我们需要逐账户、逐订单的处理意见，以及从10月末至12月交割的期限安排。各日期的计划头寸、结算价和权益见所附快照；它们是独立的资金规划基线。

材料位于`/workspace/input-data/`。F047原DOCX及F042原HTML是本次使用的规则版本，可读副本帮助定位。`futures_snapshots.csv`、`option_requests.csv`、`proposed_trade_plans.csv`和`proposed_option_quotes.csv`是待审核底稿；`planning_calendar.csv`按年度休市公告和常规周末形成基准交易/工作日，内部后台值守另列字段；日期推导使用基准列。`calendar-notice-basis.md`给出公告依据及后续临时变化口径。11月24日内部后台暂停，需要安排代理办理和回执确认。`scenario_assumptions.json`说明资金测算口径，`data_dictionary.md`说明字段、关联和引用，`input_source_map.json`列明材料角色。规则原件与内部规划参数应在结论中分别引用。

请完成以下工作：

1. 提取交易乘数、报价单位、交割单位、阶段保证金、各类主体的单向限仓及持仓/交易数量要求。逐R快照核对多、空方向及相应阶段，计算VM、结算后总权益、毛额保证金和追加资金，保留输入、公式及结果之间的计算链。
2. 推导期权到期和行权/放弃申请截止、期货最后交易日、两日交割安排及20%保证金开始日期。解释这些期限对应的业务动作，并列出计数过程。
3. 逐O请求审核时间和持有数量。按资金规划口径将有效行权转换为期货方向和新增VM，分别叠加到R03、R11并复算资金及单向限仓。分别说明请求有效性和行权后头寸/资金状态，给出操作前的控制条件。
4. 独立审核TP01–TP04的每笔开平数量与计划后持仓，提出处理意见、依据和资金操作约束。对于底稿中需要核查的异常，说明普通交易可解决的范围、尚待确认的事项和升级路径。
5. 核对Q01的报价网格，列出相邻合法价位、每手及拟报价数量一个tick的金额，给出交易员重报所需的信息。
6. 按期限和风险排序形成可分派的整改安排，逐项给出具体差额、行动、处理期限及支持条款/表行。

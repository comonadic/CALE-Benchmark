# Finance01 verifier

`test.sh` is the native Harbor entrypoint. It runs `offline_verifier.py` in a fresh separate verifier environment after `/workspace/output` has been restored. The image contains only declared office/PDF tools and agent-visible inputs; tests and solution are supplied at their own phases.

`evaluate.py` is the portable objective core. It discovers a business handoff table by the public headers in `复核索引字段.json`, never reference coordinates. It reads real XML facts/formulas, recalculates with a Decimal interpreter, and falls back to real LibreOffice for supported native formulas outside that interpreter. Native recalculation removes stale formula caches and uses an isolated profile. It awards at most 80 points and leaves all 20 professional semantic points pending.

Scoring examines 72 source amounts and scope/period/units/pages, all 17 bridge terms and contributions, two full input perturbation vectors, 34 individual source-to-CFO perturbations, independent controls, inventory provisions and AR/AP/CL balances. Raw disclosed NP inputs are valid. Different sheet names, index locations, source/model layouts, SUMPRODUCT, full-precision scaled displays and signed residual conventions are permitted. Tests of these alternatives and material formula errors are in `private/authoring/challenge.py` and the associated detailed logs.

The native wrapper follows the shared offline-container rubric bridge v1. It sends complete extracted visible inputs, the entire submitted memo, every XLSX populated cell with actual formulas/cache labels/coordinates, objective assertions, hashes and the trusted M1–M4 rubric. It seals the canonical `request_sha256`, then waits for an actual independently produced `/logs/verifier/judge-response.json`. Credentials stay on the host. It checks digest, actual identity, exact criterion coverage, finite score ranges, reason and concrete positive-credit evidence before final reward `(objective earned + semantic earned)/100`. No keyword matches, reference text equality or static answer-hash whitelist award semantic credit.

The wrapper clears stale rewards and initializes `report.json` to `verifier_failure`, `valid:false`. Empty required workbook earns a real deterministic zero without calling a judge. Source extraction/LO execution failures, missing or malformed judge response and timeouts retain the error report but produce no reward files; Harbor0.17.1 ignores the shell exit code when parsing rewards, so a failure must not leave a zero score that looks valid. Successful completed grading writes both reward files. The objective CLI's 0.8 reference score is only a local partial result, not native full-score validation.

Local bridge request extraction can be inspected with `--prepare-only`. This does not call a model or award professional credit. The bridge accepts `independent-reviewer-rubric` with an actual recorded reviewer identity/method/time as well as `independent-model-rubric`. Current execution uses an independent Codex reviewer and never uploads material to an unapproved external provider. Actual Docker/Harbor/Forge and independent judgement are coordinated by root under the shared lifecycle lock.

Reviewer identity includes `reviewer_id`, a nonempty `method`, and ISO `reviewed_at` or `executed_at` with a timezone. The original author and the package repairer cannot provide the independent grade. The adapter recomputes the canonical request digest and both candidate artifact byte hashes after the review wait; changed, added or deleted candidate artifacts invalidate verification without reward. The package peer's 14 local protocol checks use controlled zero-credit response fixtures and do not constitute genuine professional assessment.

Before any NOP or candidate-format result, `input-hashes.json` checks the complete fixed input set, `grader-hashes.json` checks the actual scoring code/context, and declared Office/Poppler tools must exist. Missing/changed trusted inputs or grader/runtime faults cannot produce a task0. Known candidate ZIP/OOXML parsing defects and non-UTF-8 memo bytes produce a completed candidate0; the catch is confined to candidate format reads. Objective execution, source extraction, Office execution and judge exceptions remain verifier failures with no reward. The production wait default remains1800 seconds.

Runtime preflight executes the chosen Office `--version` and Poppler `-v`, each with a5-second timeout. Both must return0 and identify the expected tool with a numeric version. An existing but nonfunctional binary therefore cannot turn an empty candidate into a valid0.

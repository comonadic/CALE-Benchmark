# 资料与口径

报喜鸟控股股份有限公司 2025 年年度报告为巨潮资讯 2026-04-25 披露版本。PDF 完整保留 224 页，物理页码与印刷页码一致。2024 年使用同份报告比较列；p7 列示无需追溯调整或重述以前年度数据。

分析范围为合并财务报表，币种人民币，原件金额单位为元。期间发生额与期末余额分开处理。资产负债表期末/期初分别对应 2025-12-31、2024-12-31。

主要资料：合并资产负债表 p77–79、合并利润表 p81–83、合并现金流量表 p85–86、七79(1)现金流量表补充资料 p181、应收账款 p128、存货及准备滚动 p140、应付账款及款项性质 p163、合同负债 p165。管理层关于利润现金差异的说明在 p31。

经营性应收和经营性应付为补充资料中的汇总调整，范围可涵盖多个科目及非现金调整。准备附注的“转回或转销”为合并列。未披露的拆分及交易明细应保留为取证事项。空白项目不等于披露了零金额；完整桥接使用实际列有金额的项目。

复核索引用于研究数据交接。`复核索引字段.json` 列出稳定指标ID及定义，不规定模型布局。`*_CONTROL` 指标显示实际控制差额：CFO为公式桥接减披露CFO；NP为主表净利润减桥接起点；ATTRIBUTION为归母加少数损益减合并净利润；DIRECT_CF为主表流入减流出减披露CFO；CONTRIB为逐项同比贡献减披露CFO同比变化；INV_NET/AR_NET为毛额减准备减披露净额；INV_ALLOW为准备期末复算减披露期末；INV_NET_CF/INV_GROSS_CF为准备复算调整减披露调整；CL为分项合计减总额。`NP24/NP25` 为桥接净利润起点，`CFO24/CFO25` 为公式桥接结果，`RATIO24/RATIO25` 为CFO/NP，`SPREAD24/SPREAD25` 为CFO减NP；`*_CONTRIB` 为对应补充资料项目的2025减2024；`*_DELTA` 为期末/本期减期初/上期，WC/NONWC为相应调整分组。`INV_NET_GAP/INV_GROSS_GAP` 为披露存货调整减简单净额/毛额期初减期末；`INV_CF_NET/INV_CF_GROSS` 为结合准备的两种存货调整复算；`AR_RESIDUAL/AP_RESIDUAL` 为披露经营性调整减单一余额法（应收期初减期末，应付期末减期初）。`INV_ALLOW_ROLL` 为准备期末复算；`AP_CAPITAL_EXAMPLES` 为附注重要应付中购房款和工程质保金期末合计。

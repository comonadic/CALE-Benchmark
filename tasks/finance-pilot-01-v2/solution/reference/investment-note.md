# 报喜鸟 2025 年利润与经营现金流审阅

截至 2026-04-25 年报披露，2025 年合并净利润为 350.495 百万元，经营现金流 636.485 百万元；2024 年分别为 520.155 和 702.231 百万元。现金流/净利润由 1.350 倍升至 1.816 倍，差额由 182.076 增至 285.990 百万元。现金转换比率提高，但现金流本身减少 65.746 百万元，故不能只据比率上升推断业务收现全面改善。起点用合并净利润；2025 年归母 341.748 百万元加少数股东损益 8.748 百万元才是合并数。年报 p7 标记无需追溯调整或重述比较数据，本底稿使用同份年报比较列。（p7、82、85、181；Bridge!D7:F15、D41:E43）

两年按 p181 全部项目加总均与经营现金流主表相符。2025 非营运资本调整为 450.649 百万元，营运资本调整为 -164.660 百万元；同比贡献分别为 +11.326 与 +92.588 百万元，再加净利润下降 -169.659 百万元，得到总现金流减少 -65.746 百万元。绝对贡献前三项是经营性应收 +307.692、经营性应付 -196.866、净利润 -169.659 百万元：应收调整由大额负值转正，缓冲另两项的不利变化，但没有完全抵销。存货调整又贡献 -18.238 百万元；无形资产与长期待摊摊销分别贡献 +28.479、+19.381 百万元。这里衡量的是间接法桥接贡献，并非各项经营现金流的独立交易归因。（p181；Bridge!D20:G38）

存货毛额增加 100.592 百万元，准备增加 29.010 百万元，净额增加 71.582 百万元。准备期初 129.891 加计提 94.847、减转回或转销 65.837，得到期末 158.902 百万元。披露存货调整 -166.429 百万元比简单净额期初减期末多负 94.847 百万元，恰与本期计提相等；比简单毛额期初减期末多负 65.837 百万元，恰与转回或转销相等。两种准备桥均精确相符，是可复核的算术关系，支持净额余额变动不能直接代替现金流调整。所用表没有拆分转回与转销，也没有逐笔购货、结算和重分类信息，不能把上述调整称为采购付款。（p77、140、181；WC!D7:F28）

应收账款毛额下降 63.585、坏账准备下降 13.032，净额下降 50.553 百万元。经营性应收调整仅为 +17.439 百万元，相对单一净额下降的差为 -33.115 百万元。应付账款增加 31.830 百万元，而经营性应付调整为 -15.670 百万元，差为 -47.500 百万元。p163 期末重要应付中有购房款 1.500 和工程质保金 28.291 百万元，已提示应付余额的款项性质并非纯经营采购；但仅有期末部分性质，不能将这 29.791 百万元从同比差额中直接扣除即宣布全对平。残差也不能单独证明错报。（p77–78、128、163、181；WC!D31:F49）

合同负债增加 33.705 百万元，分项为客户预收 +19.966、贵宾卡 -0.593、其他 +14.332 百万元，分项到总额勾稽一致。余额受预收及收入结转等影响，不能等同当年预收现金或单独解释宽口径应付调整。公司 p31 以折旧、减值、摊销解释利润现金差异，方向获得桥接支持，但仍不足以解释全部同比驱动。（p31、165；WC!D52:F57）

下一步应向财务部索取：一是经营性应收/应付补充资料科目映射，列明期初、期末、准备变动、非现金事项及合并范围调整，以复核两项残差；二是应付账款运营采购与资本支出分类明细，含上述购房和工程款的期初余额、新增、结算及重分类，避免用期末存量解释全年变动；三是存货准备转回/转销拆分及其对应出库成本，配合存货入库、付款对账表判断现金占用。取得上述资料前，本结论限于披露实际数的算术复核与收现质量线索，不延伸为未来现金流预测。

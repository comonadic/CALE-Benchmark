# 项目需求与谈判授权

审阅日期：2026年10月11日。甲方：澄禾零售数据有限公司；乙方：矩研技术有限公司。双方尚未签约。采购员填入项目条款后附上乙方商务和运维安排，形成`合同主文及附件工作稿_v0.docx`，请法务按下列已批准需求修改。

## 业务范围和确认事项

R01 原始数据：计划提供80,000条企业订单记录，字段仅为企业订单标识、区域、SKU、数量、金额。业务团队将处理范围限定为已不可逆去标识化、无可识别自然人信息且不涉及重要数据的企业订单数据，并由甲方确认有权委托处理。签约前仍须由甲方数据负责人确认实际数据范围及提供权利；现阶段交付资料不含行级订单文件。

R02 目的与结果：仅供甲方内部销售质量分析，做清洗、归类和汇总。结果A为全部80,000条的标准化明细及与原始记录一一对应的追溯表；结果B为24个品类的汇总分析报告。A须包含全部输入记录的处理状态及去重理由，不能直接删除失败记录；B须解释处理规则。A抽样字段准确率不低于99.5%，重复记录率不高于0.1%；B覆盖24品类且金额与经核验A汇总一致。禁止外部数据补充、模型训练、乙方营销、向其他客户披露或服务、境外存储或访问。范围、环境、地点、数量或用途变更，须先经过甲方内部审批并由双方事先书面确认。

R03 验收：乙方交齐A、B、追溯表、规则文档及完整交付清单后开始检验。项目经理书面接收不等于验收。检验期限10个工作日，自完整交付的次工作日起计算；现阶段按周一至周五安排，签约前由双方确认法定假日日历。A随机抽取2,000条，以甲方原始记录逐字段比对，准确率=核对正确的字段数/实际核对字段总数；重复率=重复记录条数/交付A总记录条数。B全量核对24品类及汇总一致性。甲方出具书面验收意见，试用、抽样、为发现缺陷而使用及逾期均不构成验收或放弃权利。乙方收到缺陷清单后5个工作日内补正，交齐修正包后同口径复验。书面意见应明确部分验收的对象。

R04 权利及交付：在双方合同关系内，甲方享有原始数据、结果A/B及过程P1“逐条清洗映射表”、P2“异常与剔除记录表”的持有、使用、经营权益，不影响第三方合法权利。乙方仅在受托目的、范围及期限内为履约持有和使用，无经营或独立训练授权，不能因费用未结清扣留交付物。乙方签约前拥有的通用软件、代码和算法保留原有知识产权；本项目规则文档、接口和必要使用说明应交付，确保甲方及后续服务商可读取、核验并继续内部使用结果和P1/P2。可采用必要的非独占永久内部使用许可或同等可用替代接口，签约前核实具体许可范围。

R05 价款：含税总价人民币480,000元。A对应288,000元，B对应192,000元。正常履约付款为20%/50%/30%，总价不得提高。第一笔条件为合同生效、履约环境具备及收到等额有效发票；第二笔为A/B全部书面验收通过及收到发票；第三笔为第十一条返还、普通副本销毁及备份到期处置的证明全部齐备、必要文档交接完成及收到发票。各笔全部条件具备后10个工作日内付款。交付或使用不单独触发第二笔，服务期届满不单独触发第三笔。

R06 部分验收终止：合同终止时，仅按已书面验收的独立结果对应价款结算，并抵扣甲方全部已付款；余额补付或超额返还，退出义务继续。供财务校核的情形为：仅A书面验收合格、B未验收，甲方已付第一笔，随后双方终止。不因B已交付收取其价款，不另叠加正常阶段50%/30%款项。请给出普遍结算公式并复算应结算、已付、净应付和返还。金额含税，本次校核不计利息及违约金。

R07 转委托：乙方拟请“云擎运维有限公司”在中国大陆境内访问明文项目数据进行日常运维，尚未取得甲方书面同意。乙方应提交主体、目的、范围、数据类别、地点、期限、安全措施和退出安排，获甲方事先书面同意后方可实施。转受托义务不低于本合同，不得再转委托；乙方承担履约责任，具体责任机制可协商，但不得以第三方自行负责排除甲方对乙方的追索。甲方监督、返还、销毁和终止权不因转委托减损。

R08 退出：处理期届满、合同终止或甲方书面要求，以先发生为准。乙方5个工作日内返还A/B、P1/P2和必要文档；普通副本10个工作日内销毁并证明。仅无法即时粒度删除的灾备副本可隔离保留，禁止主动访问和其他使用，最迟触发后30个自然日随备份轮换彻底删除并证明；灾难恢复不重启处理权限。确有法律强制留存义务时，须说明具体依据、最小范围及期限，事先通知甲方（法律禁止通知除外）、隔离且仅为该义务使用，义务结束后3个工作日内销毁并证明。目前未提供具体强制留存事项，乙方如主张留存须补充依据。

R09 优先级：附表可细化技术指标，不能以附件日期、乙方平台规则或附件B的优先条款推翻R01-R08。请确定可执行顺序，明确主文控制的商业安排与附件A技术细化事项；后续变更须双方书面同意且明确修改位置。主文、附件A/B冲突文本应同步修改。

R10 谈判授权：R02用途与范围、R04权益与工具权利分离、R05总价与触发条件、R07事先批准和R08退出控制为底线。可调整语言、责任机制和执行细节，但不得降低底线。质量、时间和付款按上述需求提出；台账可列供法务或业务审批的备选，并标清尚待批准。

# 后续程序安排测算

以下事实在基准日2025年4月4日均未发生。为安排后续工作，假定各模块一旦触发，会发生下列日期；除明确的互斥/独立模块外，按国内普通程序开庭分支计算，无期限延期、无程序中止。

F01：2025年4月25日仲裁庭组成，双方当日收到组庭通知。用于国内普通程序裁决期限和组庭后已知回避事由的期限。

F02：2025年4月25日收到某仲裁员书面披露。若客户基于该已披露事项申请回避，请计算适用期限、说明与F01一般回避期限的关系，并列出评估回避理由需要核实的资料。

F03/F04：2025年5月9日收到首次开庭通知，定于2025年5月22日09:00开庭。客户当日才得知项目负责人同期已有不可变更的培训，希望延期。本次测算按理由得到支持处理，是否批准仍由仲裁庭决定。计算正常最迟通知日、目前通知间隔和书面延期申请期限；短通知并不自动导致延期或停止程序。

F05：互斥书面审理模块。若仲裁庭改为仅书面审理，本公司计划2025年4月10日10:00提交第一次实体答辩。用于管辖异议事件边界；此模块不与F04首次开庭分支合并。

F06：独立裁决后模块。假设国内普通程序裁决2025年8月25日作出、纸质裁决书2025年9月9日收到。C01—C04中的胜负不预设。需为可能发生的计算笔误、已提交反请求漏裁准备两种申请路线，应按各自适用范围办理。

F07：仅在F06模块中，假设仲裁庭2025年10月1日收到客户有效的书面更正申请或补充申请；如确有错误/漏裁，计算仲裁庭作出相应文书的期限。两种申请分别按对应条件准备，不代表实际必然同时发生。

F08：如反请求手续及缴费完备，2025年4月21日申请人收到反请求受理通知；用于监测对方反请求答辩日期，责任人属于对方，本公司只监测。

F09：截至基准日未收到反请求缴费通知，机构规定的缴费日期未知。填写“待缴费通知”及收到后确认/支付的步骤，收到后再填写机构指定日期。

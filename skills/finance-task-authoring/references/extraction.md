# 金融材料的抽取与组包

可单独用于资料整理和 reference 库维护。先盘点给定原件与覆盖范围，再按实际用途抽取；没有造题需求时不必建立 rubric。造题时将下述证据文件归入 `private/evaluation/`，并与评分项连接。

## 从文件到可复算事实

1. 原件只读保留，解析副本与原件用 content_hash 连接。PDF 页码区分物理页和印刷页；HTML 用标题与段落片段定位；XLSX 记录工作表与单元格。
2. 将表格的多级表头、合计行、币种、单位、报告期和脚注一起抽取。跨页拼表保留每页位置。金额为空不自动当 0，破折号、无披露和不适用分开编码。
3. 每个关键事实记录：`fact_id, entity_id, metric, raw_value, normalized_value, unit, currency, period_start, period_end, as_of, scope, role, document_id, locator, source_quote`。
4. `role` 至少区分实际披露、管理层预测、评级意见、任务给定假设。只在知道换算规则时规范化；原始数字始终保留。
5. 用单独的 reconciliation 表记录财务主表与附注、债务总额与分项、期初加变动到期末的差异。记录舍入容差和差异解释，不能为“对平”自动改值。

## 计算与条款抽取

每条计算写 `calc_id, expression, input_fact_ids, output_unit, rounding, tolerance, assumptions`。例如流动比率的分子和分母必须处于相同合并范围与时点；现金债务覆盖指标需按题面定义选用现金与债务。

每项条款写 `clause_id, subject, event, condition, formula, priority, deadline, exception, locator`。支付顺序先画有向依赖，再写模型；触发条件注明是否严格大于、计量日和补救期。

| 工作族 | 关键抽取对象 | 组包锚点 |
|---|---|---|
| 股票/审计 | 分部、政策、重述、营运资本、附注勾稽 | 公司代码 + 期间 + 合并范围 |
| 信用/项目融资 | 到期、担保、契约、资金用途、项目预测 | 主体 + 债券/项目号 |
| ABS/REITs | 资产池、分配顺序、费用、触发与运营 | 产品 + 分配/报告期 |
| 银行/保险 | 资本级别、风险加权分母、监管表版本 | 机构 + 监管口径 + 日期 |
| 基金/衍生品 | 持仓覆盖、净值口径、乘数、结算与保证金 | 产品/合约 + 日期 |
| 税务/FP&A | 期间、科目映射、调整事项、预算版本 | 纳税主体/部门 + 期间 |

## 抽取质量检查

- 关键分析或评分项涉及的每个值都回看原页；非关键字段采用按格式和风险分层抽查。
- 对单位、负号、百分数和数量级做规则校验，失败时回原件；不因值极端而丢弃真实风险材料。
- 同名主体做实体消歧，证券简称变化保存别名。
- 程序计算使用规范化值，解释和引用保留原件值与位置。
- 产出 `evidence.json`、`calculations.json`、`clauses.json` 与 `reconciliation.csv`；每个 rubric criterion 引用其中稳定 ID。

## 解析层的入库核验

文本长度只用于发现异常，不作为完整度判定。按页或内容块检查解析覆盖，抽查原件与解析文本的字符、阅读顺序及表格关系；关键内容解析失败时更换解析器或使用 OCR，保留处理方式、原件哈希与定位。缺文本的封面、签章或空白页与缺失业务内容分别记录。

数字与文字可能分属不同解析层。关键财务表逐项核对单位、表头、负号和比较期；OCR 文本未经原表复核，不直接作为金标准计算输入。

# 从 金融 input-data 推导题目的示例

以下是方法演示，不表示这些文件已在本项目中下载或生成了真实题。

**给定材料**：某公司的两年年度报告及一份更正公告，没有用户指定的问题。

1. 盘点文件，确认报告期间、合并范围、单位、更正对象及附注是否齐全。抽查现金流和营运资本相关表格。
2. 提出候选：A 盈利到现金流桥接；B 跨期营运资本变化与更正影响；C 债券契约压力测试。
3. 若材料有完整财报但没有契约条款，排除 C；若更正集中在应收款且覆盖两个期间，选择 B。选择理由由实际读取结果决定，不能照抄本示例。
4. agent 自主设定财务分析角色，写出要求复算与解释变化的 instruction，确定 `analysis.xlsx` 和 `memo.md` 两项交付。日期使用材料实际可得时点；更正影响需要明确比较口径。
5. 将选定原件放入 `workspace/input-data/`；制作私有参考工作簿、事实定位、公式依赖与容差；保持 `workspace/output/` 为空。
6. 对单位错误、合并/母公司混用、重述前后混用和硬编码结果做验证器挑战。需要真实桌面重算时再配置 office-desktop 并试解。

若实际材料只有单期报告，就重新选择单期勾稽或披露一致性核查，不捏造比较期。最终交付完整 [题目文件夹](output-contract.md)，不只提供以上候选建议。
